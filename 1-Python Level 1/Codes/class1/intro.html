2. What Is a Programming Language?

Bridging the gap between human thought and machine action

Simple Definition: A programming language is a formal language used to write instructions that a computer can understand and execute.

🙋‍♂️ What Humans Understand

  • ✔️ Open Chrome
  • ✔️ Search Google
  • ✔️ Play a video

💻 What Computers Understand

They only understand 0s and 1s (Binary)

10110010 00101101

Writing directly in binary would be impossible for large programs. Therefore, programming languages were invented to make our lives easier!

5. Types of Programming Languages

Low-Level vs High-Level Languages

Low-Level Languages

Closer to hardware (e.g., Machine Language, Assembly Language). 

MOV AX, 5
ADD AX, 2
  • Advantages: Very fast, very efficient
  • Disadvantages: Hard to learn, hard to maintain

High-Level Languages

Closer to human language (e.g., Python, Java, C++, JavaScript). 

x = 5
y = 2
print(x + y)
  • Advantages: Easy to read, easy to write
  • Disadvantages: Slightly slower execution (but worth the trade-off!)

12. What About Other Languages?

Understanding the broader ecosystem

12. What Is C?

Created by Dennis Ritchie. Purpose: System Programming, Operating Systems, Embedded Systems.

  • Pros: Very fast, direct hardware control.
  • Cons: Difficult for beginners.

13. What Is C++?

An extension of C created by Bjarne Stroustrup. Used for Game development, Graphics software, and High-performance applications.

14. What Is Java?

Created by James Gosling. Highly popular for Enterprise software, Android development, and Banking systems.

15. What Is JavaScript?

Runs mainly inside web browsers. Used for Interactive websites, Frontend development, and Full-stack web apps.

Without JavaScript, websites would be mostly static!

18. Which Python Version Should You Learn?

For MCA, Generative AI, and future AI Engineering: ✅ Learn Python 3 only. Do not spend time learning Python 2. Current AI tools (PyTorch, TensorFlow, LangChain, Hugging Face) all require modern Python!
